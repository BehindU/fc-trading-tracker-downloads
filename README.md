# FC Trading Journal downloads

[Download the latest Windows installer](https://github.com/BehindU/fc-trading-tracker-downloads/releases/latest)

Install version 0.4.0 once over your existing installation. Future updates download inside the app; choose **Restart to update** when ready. Your journal, categories and settings remain on your PC. There is no need to uninstall first.

This repository contains release downloads and update metadata. The development repository remains private. Trading history and EA sign-in details are never uploaded here.

Windows x64 preview, currently unsigned. The app must be running and the PC awake to collect data from your signed-in EA Web App session. This is an unofficial app.
